# SmallGames

Coleção de joguinhos pessoais. Cada pasta é um projeto Vercel independente.

## Projetos

- **`platform/`** — página central que lista todos os jogos.
- **`wordle/`** — clone do Wordle em português (Palavrim).

Cada subpasta contém um `index.html` estático e pode ser deployada
diretamente como um projeto Vercel apontando o root para a pasta correspondente.

- Quiz Pianistas — https://quiz-pianistas.vercel.app
